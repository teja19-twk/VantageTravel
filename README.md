# 🌍 VantageTravel

**VantageTravel** is an AI-powered Smart Tourism Platform that helps travelers make smarter, data-driven travel decisions. It uses Machine Learning to predict **trip budgets, visitor volumes, and climate conditions** for better destination planning.

## ✨ Features

* 💰 **Trip Budget Prediction** – Estimate travel expenses based on trip details.
* 👥 **Visitor Prediction** – Predict tourist volume and identify potential crowd levels.
* 🌦️ **Climate Prediction** – Analyze and predict climate conditions for travel planning.
* 📊 **Data-Driven Insights** – Uses historical tourism, travel, and climate data.
* 🖥️ **Interactive Dashboard** – User-friendly interface built with Streamlit.
* 🤖 **Machine Learning Models** – Trained and evaluated using relevant tourism datasets.

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
cd VantageTravel
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Backend

Navigate to the backend folder:

```bash
cd "App files/Backend"
```

Run FastAPI:

```bash
python -m uvicorn main:app --reload
```

### 4. Run the Frontend

Open another terminal and navigate to:

```bash
cd "App files/Frontend"
```

Run Streamlit:

```bash
python -m streamlit run app.py
```

The application will open in your browser.

## 📊 Machine Learning

VantageTravel includes separate prediction components for:

| Prediction        | Model / Approach            |
| ----------------- | --------------------------- |
| 💰 Travel Budget  | Machine Learning Regression |
| 👥 Visitor Volume | Machine Learning Regression |
| 🌦️ Climate       | LSTM-based prediction       |

The models are trained using historical and processed tourism-related datasets and saved for integration with the application.

## 🎯 Objective

The main objective of VantageTravel is to simplify tourism planning by providing travelers with **estimated costs, expected visitor levels, and climate insights** through an easy-to-use AI-powered platform.

## ⚠️ Disclaimer

Predictions generated by VantageTravel are **estimates based on historical data and trained machine learning models**. Actual travel costs, visitor volumes, and weather conditions may vary. The predictions should be used for planning purposes and not as guaranteed values.
